# E-Commerce Data Analysis 

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of an e-commerce dataset using Python and data analysis libraries.

The main objective is to explore customer characteristics, identify patterns, visualize distributions, and gradually develop insights into customer behavior and business performance.

### 🚧 Project Status: Work in Progress

**This project is not yet complete.**

The current notebook represents an initial example of the data analysis process. So far, the analysis has focused primarily on the `customer_master.csv` dataset.

Several additional datasets still need to be cleaned, explored, analyzed, and integrated to complete the overall project.

The current work is intended to demonstrate the initial analytical approach rather than present a final or comprehensive business analysis.

## Current Analysis

### 1. Data Exploration and Quality Checks

- Dataset structure and dimensions
- Data types and descriptive statistics
- Missing value detection
- Duplicate record identification
- Customer ID uniqueness
- Basic data consistency checks

### 2. Customer Demographics

- Customer age distribution
- Gender distribution
- Customer segment distribution
- Gender distribution across customer segments

### 3. Geographic Analysis

- Customer distribution by country
- Customer distribution by region
- Geographic differences in customer acquisition costs

### 4. Customer Acquisition Cost (CAC)

- Distribution of customer acquisition costs
- Average acquisition cost by country
- Average acquisition cost by region
- Customer acquisition cost across customer segments

### 5. Customer Segmentation

- Exploration of customer segments
- VIP customer distribution across countries
- Comparison of customer characteristics across segments

### 6. Data Visualization

Various visualizations are created using Matplotlib and Seaborn, including:

- Histograms
- Bar charts
- Horizontal bar charts
- Distribution plots
- Comparative visualizations

## How to Run

1. Clone or download the repository.
2. Install the required Python libraries.
3. Make sure the required datasets are available locally.
4. Open `Data_Analysis_for_E-commerce.ipynb` in Jupyter Notebook or a compatible Python environment.
5. Run the notebook cells sequentially.

Install the main dependencies using:

`pip install pandas numpy matplotlib seaborn jupyter`

The current notebook expects the customer dataset at:

`data/customer_master.csv`
